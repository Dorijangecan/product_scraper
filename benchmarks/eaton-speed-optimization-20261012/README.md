# Eaton scrape speed audit (2026-10-12)

## Final source-learning rerun

The final cold rerun after exact source and classification rules, per-SKU results, unresolved field locations, timing comparison, and limits are recorded in [CONTINUATION-20261012.md](CONTINUATION-20261012.md). It supersedes this file’s earlier post-change timing values and first-pass group B type/current notes (including the earlier statement that TPC2234-3866 current was blank).

## Method

All 30 catalog numbers were checked against `data/scraper.db` run history and `page_cache`, benchmark fixtures, saved run reports, and text artifacts before selection. Each invocation used `BENCHMARK_ISOLATED_STORAGE=1` with a fresh runtime DB/cache; inputs were SKU-only fixture manifests. The first group A attempt ran serially until the harness hit the 180 s timeout on `5FTCKIT`, so remaining cases were measured as individually isolated cold invocations. Group A post-run and group B used one isolated cold invocation per SKU. Product reports preserve exact PDP URL, result fields/attributes with parser and source URL, documents, quality gates, and elapsed time. Each report’s isolated runtime `scraper.db` preserves fetched page URLs/statuses.

[`request-evidence.csv`](request-evidence.csv) preserves each measured run’s elapsed result and the cached HTTP request URL, method, status, content type, effective URL, fetch time, and body path. The JSON reports retain discovered document/download URLs and extracted PDF rows. The benchmark did not emit per-request retry/backoff durations for every case; only `1173A-100` has complete per-stage debug timings below.

An initial draft of the new link matcher missed Eaton’s plural “Catalogs” label and hit the 180 s timeout on `1173A-100`; its report is preserved among the benchmark JSON files but excluded from the final post-change comparison. The corrected matcher was then verified on captured official HTML and the clean 7.511 s run.

Percentile is nearest-rank (ceil(0.90*n)); medians use the midpoint for even samples. Totals are the sum of per-SKU elapsed times (not wall-clock batch time).

Group A built-in quality stayed 9/15; therefore no full quality acceptance is claimed.

## First-pass mismatches (later exact-source fixes applied)

This section records what the first pass found. The final type/current resolutions and remaining failures are in [CONTINUATION-20261012.md](CONTINUATION-20261012.md).

- `1173A-100` was the measured shared bottleneck: its exact PDP linked the Eaton catalog page statically, but the parser discarded it because the generic catalog title/URL omitted the SKU. Directly opening that link and using the existing exact-row PDF parser avoided the 110 s speculative fallback while preserving the exact page identity and exact-row voltage evidence.
- The remaining group A built-in failures were present before the optimization too (9/15 before and after). Official PDP evidence shows type rules/fixture expectations need review: `197509` has Product Type “Control relay” while classification returned PLC; `DG1-32088FN-C21C` says “Variable frequency drive” while the classifier emits “Variable Speed Drive”; `SK6-6` says “Surge protector” while the classifier emits Connector; `BREVEM2040` says “BR EV smart breaker charger” while classification is unknown. `5FTCKIT` remains missing current, and `XV-303-15-C00-A00-1D` remains missing voltage. These values were not forced into the output.
- Group B surfaced related but distinct mismatches: exact page types are `Capacitor bank` (`225MCSR631MW`), `Key-operated actuator` (`038805`), `Potentiometer` (`232233`), `Power supply unit` (`229424`), `Power supply` (`PS-8-LP`), and `Compact power supply` (`PS256B-04B1`). Each exact page and extracted source record is linked above.

## Learned reusable locator and verification

Reusable rule saved in `src/server/scrapers/eaton.ts`: on an exact Eaton `skuPage.<SKU>.html` PDP, retain official Eaton PDF links whose labels identify catalogs/brochures even when their generic family URL/title omits the SKU. These documents remain enrichment candidates only: the existing exact-SKU row identity gates still determine whether any field is usable. Verified directly on `1173A-100` (90–132 V AC at 60 Hz was sourced from the exact row in the official Sensing Solutions, Legacy Sensor Products catalog) and exercised on `5FTCKIT` and `XV-303-15-C00-A00-1D`; no unsupported value was filled.
